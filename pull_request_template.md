# What is DCO sign-off?  Why is it required?

DCO stands for [Developer's Certificate of Origin](https://github.com/git/git/blob/v2.18.0/Documentation/SubmittingPatches#L304-L349).

All commits are REQUIRED to be DCO signed-off in case we need to track down and handle legal and/or technical issues.

To DCO sign-off your commits, you MAY either

- run the `git-commit` command with [the `-s` option](https://git-scm.com/docs/git-commit#git-commit--s), or

- just add a line in your commit message in this format:

    ```
    Signed-off-by: yourFirstName yourLastName <yourEmail@example.org>
    ```

    ... or

- if you are using [GitHub Desktop 3.5.7](https://github.com/desktop/desktop/releases/tag/release-3.5.7) or later, when making a new commit or amending one (only in your PR), click :gear: and ensure that **Add Signed-off-by trailer** is checked.

For more information, check out [how PRs are checked for DCO sign-off](https://github.com/probot/dco#how-it-works).

Thank you very much.
